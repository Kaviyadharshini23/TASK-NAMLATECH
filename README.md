# Hotel List Page – NamlaTech Task

## About the Project
This project is a simple Hotel List Page developed as part of the NamlaTech task. It allows users to view hotel details, search hotels, add new hotels, edit existing hotel information, and delete hotels.

The application is built with a simple and responsive user interface.

## Technologies Used

### Frontend
- React.js
- Redux
- HTML
- CSS

### Backend
- Node.js
- Express.js

## Features
- Display hotels as cards
- Search hotels by name
- Add a new hotel
- Edit hotel details
- Delete a hotel
- View complete hotel details
- Display hotel location using latitude and longitude
- Image upload and preview
- Price validation
- Responsive user interface

## Backend Details
The backend is developed using Node.js and Express.js.

Since this task uses dummy data and does not require a database, hotel details are maintained in a JavaScript file. The backend provides basic API operations for adding, viewing, updating, and deleting hotel details.

The data is temporary and will reset when the backend server is restarted.

## How to Run the Project

### Frontend
npm install
npm run dev


### Backend
cd backend
npm install
npm run dev
